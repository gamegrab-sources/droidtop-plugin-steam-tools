# Changelog

## 0.1.0

- First version: free Steam games claimed in the background (Steam's product changes, filtered to what is free to own, within droidtop's hourly limit), keys redeemed in bulk with each result, and the games you name shown as played. Uses droidtop's Steam account API (docs/plugin-api.md 3 G8), so it needs a droidtop with `steam.account`.
